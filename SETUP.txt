Myths of the Veil v26 - online setup
1. supabase.com -> New project.
2. SQL Editor -> paste supabase-setup.sql -> Run.
3. Project Settings -> API: copy Project URL + anon public key into config.js.
4. Authentication -> URL Configuration: Site URL = https://myths-of-the-veil.netlify.app
   (optional) Authentication -> Sign In / Providers -> Email: turn off "Confirm email" for instant sign-up.
5. Copy all these files into your Netlify folder, then in PowerShell:  netlify deploy --prod --dir .
Without config.js values the game runs single-player as before.
